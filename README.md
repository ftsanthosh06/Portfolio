# Santhosh Kumar — Portfolio

A responsive, single-page developer portfolio in a warm paper and forest green Bento Grid style.

## View it

Open `index.html` in a modern browser. No build tools or package installation are needed. Google Fonts are loaded online; system font fallbacks are included.

## Included

- `index.html` — portfolio content and links
- `styles.css` — responsive layout, warm palette, custom artwork and motion
- `script.js` — lightweight scroll reveal interactions
- `assets/santhosh.jpg` — supplied portrait, toned for the portfolio palette

Cards include a flip control with extra details and a six-dot drag grip for rearranging cards on desktop. The pointer label changes over the card, grip, and flip control. On touch screens, flipping remains available while card dragging is disabled.

The contact buttons link to LinkedIn because no email address was provided. Update the project year or add technology names as needed.
